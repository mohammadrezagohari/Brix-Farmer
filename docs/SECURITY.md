# Security

Dashboard security extension: active-account middleware denies all private actions after suspension (logout exempt). New admin mutations are Gate-protected and audit reason/evidence in the same transaction. Tenant middleware remains mandatory even for platform admins accessing tenant data. Farmer role is scoped to an organization; `access:create --farmer` provisions one using a hidden interactive password. Trader cannot edit farmer listings. Draft publication needs moderation and verified KYB; public reservation rechecks listing/seller eligibility while locked. CRM cross-organization partner references and stage changes are denied. Database raw password fields are never returned by admin user listing.

KYB in this milestone records a human decision and textual evidence/reference only; secure document upload/review is still pending. No export compliance or financial authorization is represented by KYB. QA seed accounts use an environment-provided ephemeral password and only local/testing environments. Browser test artifacts are ignored by Git and excluded from images because they may contain synthetic test form inputs. No production credential is seeded.

Access extension: non-fillable is_platform_admin is granted only via trusted interactive CLI, protected by a platform-admin Gate. Admin endpoints are read-only aggregates/organization listings. Trader remains an organization membership role. Cross-organization trader access, invalid type escalation, public admin flag injection and duplicate CLI account overwrites are tested. Admin has no organization membership bypass. Create accounts using access:create, entering passwords through the hidden prompt; no default password or public admin registration exists.

Sanctum session authentication, Laravel web CSRF protection, password hashing, session regeneration, login/registration throttling, JSON API errors and server-validated organization membership. Organization IDs are context hints only. Suspended organizations cannot access inventory. Owner/manager can create lots; owner/manager/buyer can reserve and release. Organization creation grants owner membership transactionally.

Same-origin browser requests pass through Next rewrites or Nginx. No cross-origin CORS allowance is needed. Keep SESSION_HTTP_ONLY=true, SESSION_SAME_SITE=lax and SESSION_SECURE_COOKIE=true behind production HTTPS. Never disable CSRF. APP_DEBUG=false in production. Secrets stay outside source control. Synthetic seeders reject production and do not print passwords.

Not production ready: invitation, KYB review, password recovery UI, email verification, OTP, exhaustive policies/resources, upload authorization, immutable database grants, compliance and audit modules are pending. Unverified suppliers cannot be reserved through HTTP, but listing eligibility and private catalogue access are not implemented. No public inventory discovery endpoint exists. Outbox consumers and reservation commitment are pending. No payment custody or legal approval is implemented.
